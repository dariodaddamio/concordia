Concordia is a local Windows application that runs official provider CLIs under your accounts and coordinates their chats, projects, approvals and workers.

This site documents the current implementation. It does not promise future panels, integrations or provider behavior that the application does not expose today.

## Start with a project

Install Concordia, connect a provider, then open a project. A chat keeps its provider identity and its explicit native session identity. Concordia can retrieve bounded source context when you ask it to.

## What Concordia owns

Concordia owns cross-provider routing, chat state, questions, approvals, project selection, commands that span providers, and local memory and harness extension points. Provider tools own authentication, native sessions and provider tools.
